## Reporting a Vulnerability

The TermMirror team takes the security of our software seriously. If you discover a security vulnerability, please do NOT file a public issue.

Instead, please send an email with detailed reproduction steps to:
📧 **security@term-mirror.dev**

Please include:
- A description of the issue and potential impact
- Detailed reproduction steps or proof-of-concept
- Any suggestions for remediation

We will acknowledge receipt of your report within 48 hours and work with you on a coordinated disclosure timeline.
